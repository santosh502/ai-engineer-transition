This directory contains notes and examples on Retrieval-Augmented Generation - a pattern for grounding LLM responses in external documents.

## Why RAG Matters

- **Reduces hallucination**: Grounds answers in real documents
- **Handles fresh data**: Answers based on real-time information
- **Domain-specific**: Can specialize models for specific domains
- **Cost-effective**: Avoid fine-tuning for every domain
